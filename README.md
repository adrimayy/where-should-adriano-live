# Where should you live?

An interactive map that scores every country and 744 cities (every US metro area and major world cities) on 26 factors (healthcare, housing, jobs, climate, safety,
freedom, clean air, corruption, working hours, disaster risk and more), using published data from sources like the WHO, the UN, the FBI, Numbeo and the World Happiness Report.
A short quiz that branches on your answers (about a dozen questions) re-weights everything for you: any languages you speak, any passports you hold, any home city. Interface in English,
Spanish, Portuguese, French, German, Chinese, Hindi and Arabic. Nothing is scored on screen until you
answer the quiz (or open a saved or shared take).

**To use it:** visit the GitHub Pages site, or open `index.html` in any browser (it also works straight from your disk).

## What's in this repository

```
index.html          The page's structure. It loads the three things below, in order.
css/atlas.css       How it looks.
data/atlas.js       Every number the page shows, in one file. Made by build.py; don't edit by hand.
data/lakes-hires.js Detailed lakes for the zoomed-in map, loaded on demand. Also made by build.py.
js/                 The page's code, one file per part, run in name order:
                    00 setup, 01 strings (English and Spanish), 02 factors and presets, 03 geography,
                    04 language and passport, 05 places, 06 scoring and the 120 recalculations, 07 quiz,
                    08 your results, 09 take/save, 10 map, 11 panels (ranking, details, weights), 12 events, 13 startup.
  i18n/             Extra interface languages (pt, fr, de, zh, hi, ar), loaded only when chosen. English and Spanish
                    live in js/01-strings.js. Check a translation with python3 tests/i18n_check.py.

pipeline/           Where the data comes from (only used to make data/atlas.js):
  sources/          Every published number, one file per topic, each naming its source and year.
                    languages.py and work_rights.py hold where each language works and who can work where.
                    air.py, honesty.py, work_hours.py and disaster_risk.py are made by import_tables.py from the downloaded files;
                    us_local.py by import_us.py, regional_jobs.py by import_eurostat.py, itdp.py by import_itdp.py and
                    world_updates.py by import_world.py.
  input/            Hand-curated inputs: places, coordinates, notes, hand estimates. See input/README.md.
  bands.py          Every rule that turns a number into a 1-5 score, in one place.
  score_published.py  Step 1: combines the sources into scores for each country and city.
  fill_gaps.py      Step 2: estimates missing values and measures how accurate those estimates are.
build.py            Runs the pipeline and writes data/atlas.js.
bundle.py           Packs everything into one file (dist/) for the claude.ai version. GitHub Pages doesn't need it.

tests/              Automated checks (see below).
docs/               METHODS (one page), APPENDIX (every source and statistic), CHANGELOG.
  reports/          Generated by the tests: OVERLAP, SPANISH_REVIEW, VALIDATION.
.github/workflows/  A monthly check that lists stale sources (tests/data_age.py).
```

Working files (`build/`, `dist/`) are not part of the repository. Code is formatted with Prettier (`.prettierrc.json`).

## Making changes

- **Page look or behavior:** edit `index.html`, `css/atlas.css` or a file in `js/`, then refresh. No build step.
- **A statistic:** edit the number in `pipeline/sources/<topic>.py`, then run `python3 build.py` (needs Python 3 with
  `numpy` and `scikit-learn`). This rewrites `data/atlas.js`, re-estimating gaps and uncertainty.
- **Add a city:** add a row to `pipeline/input/cities_added.json` and its numbers to `pipeline/sources/`, then
  `python3 build.py`. Missing numbers are estimated automatically and marked on the page.
- **How strict a score is:** the thresholds in `pipeline/bands.py`, then `python3 build.py`.
- **The sample take** (the tests' fixed case): `SAMPLE` in `js/07-quiz.js`.
- **Wording (English or Spanish):** `js/01-strings.js`, then `python3 tests/spanish_review.py` to refresh the review sheet.
- **Wording in another language:** `js/i18n/<code>.js`, then `python3 tests/i18n_check.py`. To add a language, copy one of
  those files, translate it, and add the code to `UI_LANGS` in `js/01-strings.js`.
- **Clean air, corruption, working hours or disaster risk, after a new release:** download the files named in `pipeline/import_tables.py`,
  run it with their paths (needs `openpyxl`), then `python3 build.py`.
- **US metro data (BLS unemployment, EPA air, County Health Rankings, Census population):** `pipeline/import_us.py`. The ACS
  file `pipeline/input/acs_2025_metros.txt` holds earnings, rent and transport to work, with each metro's CBSA code.
- **European regional unemployment:** `pipeline/import_eurostat.py` with the Eurostat `lfst_r_lfu3rt` spreadsheet and the
  NUTS 2 boundaries from github.com/eurostat/Nuts2json (needs `shapely`).
- **Car dependence (ITDP Atlas):** `pipeline/import_itdp.py` with the `atlas_cities_*.csv` files from atlas.itdp.org.
- **Freedom House, UNODC homicides, ILO working hours:** `pipeline/import_world.py`.
- **Map lakes:** `pipeline/import_lakes.py` with Natural Earth's `ne_110m_lakes.geojson` and `ne_50m_lakes.geojson`.
- Each importer's docstring lists the exact files and where to download them; each output file records the files' checksums.
- **Where a language works, or a visa rule:** `pipeline/sources/languages.py` or `work_rights.py`, then `python3 build.py`.

## Run the tests

```
python3 tests/test_page.py      # clicks through the quiz, map and language switch on desktop and mobile
python3 tests/test_numbers.py   # checks specific numbers (money after rent, bands, rounding, rules)
python3 tests/test_gestures.py  # pinch and pan keep the map under your fingers
python3 tests/profiles.py       # top 10 for the sample take and three very different people
python3 tests/validate_sources.py   # held-out checks on the Nov 2026 sources; writes docs/reports/VALIDATION.md
python3 tests/robustness.py     # sensitivity: weights, cut-offs, rescaling, combining and gap-filling varied together (Sobol indices)
python3 tests/overlap.py        # which factors move together; writes docs/reports/OVERLAP.md
python3 tests/wealth_bias.py    # how much of the ranking national wealth explains
python3 tests/data_age.py       # sources older than 12 months
python3 tests/spanish_review.py # writes docs/reports/SPANISH_REVIEW.md
python3 tests/i18n_check.py     # every translation has the same keys, placeholders and tags as English
```

The tests need Playwright and Chrome. They don't use the internet: map and library downloads are replaced with stand-ins.
