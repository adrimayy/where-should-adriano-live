# Where should Adriano live?

An interactive map that scores every country and 137 cities on 19 factors (healthcare, housing, jobs, climate, safety,
freedom and more), using published data from sources like the WHO, the UN, the FBI, Numbeo and the World Happiness Report.
It opens on equal weights, with Adriano's own priorities one tap away; a 5-question quiz (or the full 20) re-weights
everything for anyone else. English and Spanish.

**To use it:** open `index.html` in any browser, or visit the GitHub Pages site. Everything runs in the page.

## What's in this repository

```
index.html               The website. This is the only file GitHub Pages needs.
build.py                 Rebuilds index.html from the data (one command, see below).

data/                    The curated starting data: places, notes, coordinates. See data/README.md.
pipeline/                How published numbers become scores.
  sources/               Every published number, one file per topic (health, safety, housing, jobs...).
  bands.py               Every rule that turns a number into a 1–5 score, in one place.
  score_published.py     Step 1: combines the sources into scores for each country and city.
  fill_gaps.py           Step 2: estimates missing values and measures how accurate those estimates are.
site/template.html       The page's layout and styles; build.py fills in the data and the script.
site/js/                 The page's script, one file per part, joined in order by build.py:
                         01 strings (English and Spanish), 02 factors and presets, 06 scoring and the 120 recalculations,
                         07 quiz, 10 map, 11 panels (ranking, details, weights, offers), 12 events, 13 startup.
tests/                   Automated checks (see below).
docs/
  METHODS.md             How every factor is measured, the rules, the statistical checks, and what couldn't be done.
  HISTORY.md             How the #1 city changed as the method improved, and why.
  OVERLAP.md             Which factors move together (generated by tests/overlap.py).
  SPANISH_REVIEW.md      Every Spanish label and quiz question, for a native speaker to review (tests/spanish_review.py).
.github/workflows/       A monthly check that lists stale sources (tests/data_age.py).
```

Generated files (`build/`, `dist/`) are not part of the repository; `build.py` recreates them.

## Rebuild after changing data

```
python3 build.py
```

This runs both pipeline steps and writes a new `index.html`. Needs Python 3 with `numpy` and `scikit-learn`.

## Run the tests

```
python3 tests/test_page.py      # clicks through the quiz, map and language switch on desktop and mobile
python3 tests/test_numbers.py   # checks specific numbers (money after rent, bands, rounding, rules)
python3 tests/test_gestures.py  # pinch and pan keep the map under your fingers
python3 tests/profiles.py       # top 10 for Adriano and three very different people
python3 tests/robustness.py     # sensitivity: weights, cut-offs, rescaling, combining and gap-filling varied together (Sobol indices)
python3 tests/overlap.py        # which factors move together; writes docs/OVERLAP.md
python3 tests/wealth_bias.py    # how much of the ranking national wealth explains
python3 tests/data_age.py       # sources older than 12 months
python3 tests/spanish_review.py # writes docs/SPANISH_REVIEW.md
```

The tests need Playwright and Chrome. They don't use the internet: map and library downloads are replaced with stand-ins.

## Common changes

- **Add a city:** add a row to `data/cities_added.json`, add its numbers to the matching files in `pipeline/sources/`,
  then run `python3 build.py`. Missing numbers are estimated automatically and marked on the page. Details in `data/README.md`.
- **Update a statistic:** edit the number in `pipeline/sources/<topic>.py` (each file names its source at the top).
- **Change how strict a score is:** edit the threshold in `pipeline/bands.py`.
- **Change Adriano’s weights:** edit `mine:` in `PRESETS` in `site/js/02-factors.js`.
- **Change wording (English or Spanish):** edit `site/js/01-strings.js`, then run `python3 tests/spanish_review.py` to refresh the review sheet.
